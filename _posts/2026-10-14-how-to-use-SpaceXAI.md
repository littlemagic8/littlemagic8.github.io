## 一、Grok + Cursor + Grok Bot 四合一的产品是什么？

X Subscription 把四条产品线合成一个订阅体系：

- **Grok**：对话、语音、Imagine 图像生成、视频生成、Build 应用构建等核心能力；
- **Grok Bot**：拥有独立持久云端计算机（浏览器 + 文件系统 + 终端）的 AI 队友。可创建多个具名 Bot，长期记忆上下文、并行协作、群组聊天、交接任务、学习技能、设置定时例程，合上电脑也能后台干活，需要审批时才通知你；
- **Cursor**：AI 原生代码编辑器，支持云端 Agent、Origin 代码托管、Bugbot 审查等，Grok 模型原生深度集成；
- **X Premium**：平台验证勾选、减少广告、创作者工具、高级分析等社交平台权益。

核心亮点有两个：

1. **共享云端计算机 + 多 Bot 协作**：Grok Bot 负责跨工具的多步骤知识工作（邮件、CRM、浏览器操作、调研等），稳定流程可保存为"技能"或定时"例程"；
2. **与 Cursor 无缝接力**：Bot 遇到编程任务直接派给 Cursor 云端 Agent，成果再回到 Bot 侧整理或演示，全程无需复制粘贴。

官方原话是：每个对应档位相比原来单独购买，"每一美元能买到的用量都更多"。

## 四、X Subscription 不同会员额度有多少？

### 谁能用？

| 你的身份 | 能用到什么 |
| --- | --- |
| Free 用户 | 每日基础额度的 Grok Chat/Voice/Imagine/Build + Cursor 入门 Agent 额度 |
| Plus 及以上个人用户 | 完整 Grok 能力 + Cursor（Grok 模型）+ X Premium 权益 |
| Premium / Super / Ultra | **解锁 Grok Bot**、云端 Agent、第三方模型、完整 X Premium+ |
| 团队席位 | Premium/Super/Ultra 按席位订阅，每个席位有独立用量池，团队共享充值余额；Plus 档不对团队开放 |
| 企业用户 | 目前多需候补或联系商务 |

### 额度怎么算？（重点）

X Subscription 的用量是**一个共享的每周池**，规则如下：

1. **覆盖范围**：只计第一方用量——Grok 聊天、Imagine、语音、Build、Grok Bot、Cursor 里的 Grok 模型，全部从同一个池子扣；
2. **跨产品共享**：池子在 grok.com、x.com、Cursor、Grok Bot 之间通用，但**各产品的消耗速率不同**（Agent 类任务烧得快，普通聊天烧得慢）；
3. **每周重置**：到点自动回满，dashboard 可查看实时用量和下次重置时间；
4. **用完了怎么办**：等下周重置，或加购 **Additional Usage**（额外用量 credit）；
5. **第三方模型单独计费**：在 Cursor 里用 Claude、GPT 等第三方模型，按 API 列表价从 Additional Usage 里扣，**不占用也不包含在订阅池内**；
6. **Auto Top-up**：可开启自动加购并设置消费上限，避免超支。
