## 一、下载并安装 Codex / ChatGPT 桌面版

### 1. 从网页版进入 Codex 入口

登录 [ChatGPT 网页版](https://chatgpt.com/)，在左侧找到 **Codex** 入口（根据官网引导的Codex入口下载即可）。

![Codex 侧边栏入口](/img/image-20260810231332237.png)

### 2. 下载 Windows 安装包

进入 Codex 介绍页后，点击 **下载 Windows 版**（按页面推荐安装包即可）。

![下载 Windows 版](/img/image-20260810231339105.png)

### 3. 运行安装程序

在「下载」文件夹中双击 **ChatGPT Installer**，按提示安装。

![双击 ChatGPT Installer](/img/image-20260810231345324.png)

若走 Microsoft Store，会显示正在下载 ChatGPT 应用，等待完成即可。

![Microsoft Store 下载中](/img/image-20260810231354779.png)

**安装完成后,点击【继续登录】,在浏览器打开之后，选择当前登录的ChatGPT账号登录时，往往就会出现手机验证了（特别是购买的ChatGPT成品账号）**。如果需要验证码，那就默默退出来，先搞好接码平台，为了避免Codex登录超时，下面咱们先把接码准备好~

## 二、在 HeroSMS 购买 OpenAI 短信号（一次性接码）

### 1. 打开 HeroSMS 并登录

官网打开：[https://hero-sms.com/?ref=831330](https://hero-sms.com/?ref=831330)

登录后确认右上角有余额（没钱先充值，金额不用太大）。

### 2. 点击「获取验证码」

顶部紫色按钮 **获取验证码** —— 从这里开始买号。

![点击获取验证码](/img/image-20260810231400911.png)

「我的购买」列表初始为空是正常的。

![我的购买列表](/img/image-20260810231406966.png)

> 若需要 **1 / 3 / 7 天等更长租期**，可在平台宣传入口或时长选项里选择。  
>
> **更长租期也只是延长「能收到短信」的时间窗口，不等于这个号永远属于你。** 本教程仍按 **一次性短时接码** 演示。

### 3. 选择服务：搜索 OpenAI

在「1. 选择服务」搜索框输入 **OpenAI**，点选 OpenAI 服务。

![搜索并选择 OpenAI](/img/image-20260810231413538.png)

### 4. 选择国家

示例选择 **英格兰 / 英国（+44）**。  

> ps: 可以选择美国之外的地区（避开高需求地区），实际以平台当前有货、价格合适为准（为了避免多次接码可以用价格较高的优质号码）

### 5. 选择时长：默认 20 分钟即可

「购买或自定义」里默认常见为 **20 分钟** 短信验证。  
本教程演示 **一次性短时接码**，选 20 分钟就可以了。

![默认 20 分钟](/img/image-20260810231424735.png)

时长可选 20 分钟、1 天、3 天、7 天、14 天等（价格不同）。

![选择时长](/img/image-20260810231419125.png)

说明一般会写：**若在有效期内未收到验证码，费用会退回余额** —— 以平台规则为准。

### 6. 下单购买

点击 **以 $x.xx 购买**。成功后「我的购买」会出现一条记录：电话号码、成本、状态（如「等待短信」）。

### 7. 等待短信：可刷新 / 取消

购买成功后状态为 **等待短信** 时：

- 约 **2 分钟** 后若还没码，可点 **刷新**（更换号码）；
- 一直收不到可 **取消**（通常未成功接码会退余额，以平台为准）；
- 失败就重新走一遍「获取验证码 → 选 OpenAI → 选国家 → 购买」。

![等待短信时可刷新或取消](/img/image-20260810231430748.png)

**建议节奏：**

1. 先在 HeroSMS 买好号、复制号码；  
2. **立刻** 去 ChatGPT / Codex 填号点发送；  
3. 再回 HeroSMS 等验证码 —— 减少Codex登录超时。

## 三、桌面端登录并完成手机短信验证

### 1. 打开桌面版，登录你的 ChatGPT 账号

启动安装好的 ChatGPT / Codex 桌面应用，使用 **继续登录** 方式用ChatGPT账号登录。

![登录 ChatGPT](/img/image-20260810231452627.png)

若出现账户选择，选中要用于 Codex 的那个账号继续即可。

![选择账户继续](/img/image-20260810231500303.png)

### 2. 出现「电话号码是必填项」

页面提示需要添加电话号码，并发送 **一次性验证码**。

操作要点：

1. 国家区号与 HeroSMS 号码一致（如英国 **+44**）；  
2. 填入刚买到的号码（注意不要重复写区号）；  
3. 发送方式选 **短信**（本次不选 WhatsApp，如需此种方式也可以给下载WhatsApp，用herosms给WhatsApp接码，再给Codex接码（因为需要使用多次手机号接收验证码就不能选20分钟，至少选一天期限的，如果需要详细指导可以添加客服V：aicygg888 或者 aicygg789 备注：WhatsApp接码））；  
4. 点击 **继续**。

![选择短信并继续](/img/image-20260810231533282.png)

### 3. 回到 HeroSMS 查看验证码

状态变为 **已接受短信** 后，后面会显示 **短信验证码**（通常一串数字）。复制它。

![已收到短信验证码](/img/image-20260810231636466.png)

### 4. 在 ChatGPT 页面填入验证码

「查看你的手机」页面输入刚收到的代码，点 **继续**。

![输入短信验证码](/img/image-20260810231553343.png)

### 5. 验证通过后继续

验证成功后按页面提示点 **继续**，完成登录授权。

![验证后点击继续](/img/image-20260810231647366.png)

浏览器若弹出「要打开 ChatGPT 吗？」，点 **打开 ChatGPT** 回到桌面应用。

![打开 ChatGPT 桌面应用](/img/image-20260810232509971.png)

## 五、用号建议：尽量降低「二验」概率

临时号已经绑过，**无法保证永远不再验**。可以做的是降低触发概率：

| 建议 | 原因 |
| :--- | :--- |
| 固定干净节点 | 频繁换国家 / 万人骑 IP 更容易风控 |
| 不做反代、不卖共享号 | 高风险行为最容易连坐 |
| 付费后正常个人使用 | 对付费正常用户通常更宽容 |
| 重要代码只信本地 | 项目文件在本地，账号出事损失更小 |
| 别把唯一找回方式押在临时号上 | 临时号失效后短信通道就断了 |

## 常见问题 FAQ

### Q1：为什么推荐选「短信」而不是 WhatsApp？

都可以，只是本次演示短信接码

### Q2：一直收不到验证码怎么办？

1. 在 HeroSMS 点刷新；  
2. 超时或失败就取消，换国家 / 换号重买；  
3. 确认 ChatGPT 填的区号、号码与平台一致；  
4. 发送验证码前先确保号码已「购买成功」再点发送。

### Q3：20 分钟够用吗？

流程顺的话完全够。建议：**先买号 → 立刻去 ChatGPT 发送 → 马上回平台抄码**。

### Q4：买 7 天长效是不是就安全了？

只是 **多几天能收短信**，不是实名手机，也不是「永不二验」。长效更贵，是否值得自己权衡；**风险本质没变**。

### Q5：二验之后有没有救？

临时号没了就很难再靠原号过验。有人会遇到风控过一阵自动缓和，**不能当承诺**。重要项目请以 **本地文件** 为准。

### Q6：会不会影响已经写好的代码？

Codex 改的是你本机项目时，**文件在本地**。账号登录出问题，一般 **不影响已保存的本地成果**。
